# Аудит энергоэффективности термического и кузнечного участка

Услуга для машиностроительных заводов: разбор реальных режимов работы печей по данным
самого предприятия с расчётом перерасхода газа и электроэнергии в деньгах и перечнем
мероприятий с оценкой эффекта.

Первый отчёт по одной печи — бесплатно, за пару дней, без остановки производства.

## Как пересобрать видеофон

Исходник не подключается как есть: с него срезается watermark, снимается цвет
и выбрасывается звук. Нужен [ffmpeg](https://ffmpeg.org).

```
GRADE="crop=1120:720:0:0,hue=s=0,colorchannelmixer=rr=1.0:gg=0.58:bb=0.26,eq=contrast=1.18:brightness=0.02,hqdn3d=4:3:6:4,gblur=sigma=1.3,scale=1000:644:flags=lanczos,fps=20,format=yuv420p"

ffmpeg -i "image/hero block.mp4" -an \
  -filter_complex "[0:v]${GRADE}[g];[g]split[a][b];[b]reverse[r];[a][r]concat=n=2:v=1:a=0[o]" \
  -map "[o]" -c:v libx264 -profile:v high -crf 36 -preset veryslow -g 40 \
  -x264-params "aq-mode=3:aq-strength=1.1:deblock=-1,-1" -movflags +faststart \
  assets/hero.mp4

ffmpeg -ss 6 -i assets/hero.mp4 -frames:v 1 -q:v 5 assets/hero-poster.jpg
```

Что здесь зачем:

- `crop=1120:720` — срезает watermark генератора в правом нижнем углу;
- `hue=s=0` + `colorchannelmixer` — убирает синеву исходника и тонирует в янтарь под палитру страницы;
- `hqdn3d` + `gblur` — гасят генеративный шум, за счёт этого файл жмётся втрое;
- `split/reverse/concat` — бумеранг: луп замыкается без видимого стыка;
- `-an` — звук фону не нужен и мешает автоплею.

Грейд запечён в файл намеренно: CSS-фильтр на полноэкранном видео пересчитывается
каждый кадр и греет слабые ноутбуки.

Итог — 1,2 МБ вместо 2,8 МБ исходника. Видео грузится только на экранах шире 860 px
без тача, вне `prefers-reduced-motion` и вне режима экономии трафика; в остальных
случаях показывается постер на 37 КБ.

## Как устроено демо

Секция «Двое суток из архива печи» считает всё в браузере: ни сервера, ни запросов
наружу, ни сохранённых данных. Три части, и разделены они намеренно.

| Часть | Что делает |
|---|---|
| `PLANS` + `buildArchive` | Синтезирует архив: 2880 точек по минуте, шум термопары, колебания регулятора, провалы на открытой двери, паузы между садками. Заодно выдаёт журнал садок — то, что на реальном объекте даёт цех. |
| `detect` | Ищет отклонения. **Плана не видит** — получает только массив температур, журнал садок и паспортный режим. Ровно то, что пришло бы выгрузкой с завода. |
| `cost` | Переводит найденное в кубометры, киловатт-часы и рубли. |

Разделение — не архитектурное украшение, а суть демонстрации: если бы детектор знал
план, он находил бы ровно подложенное, и грош цена такому показу. Проверяется это
глазом — из шести садок помечены пять. Шестая идёт в пределах паспорта, и порог
отсечки (три сигмы шума термопары, посчитанные по самому архиву) её отбрасывает.

Три места, где очевидное решение не работает, — если будете править, не наступите
второй раз:

- **Выдержку нельзя искать по производной.** Минутный шум термопары рвёт любой порог
  наклона. `findSoak` берёт полосу 4 °C от максимума садки.
- **Начало провала на двери сглаживание сдвигает назад** на минуту-полторы, и дверь
  выходит «открытой» на 15–20 % дольше, чем была. Начало уточняется по сырому ряду.
- **Три статьи нельзя подсвечивать одинаковой заливкой** — график превращается в кашу.
  Холостой ход — полоса во всю высоту, перетоп — площадь между паспортной полкой
  и фактом, дверь — узкий штрих.

Классы и идентификаторы демо с префиксом `dm-` / `dm`: `.k`, `.v`, `.t`, `.d`, `.card`
и `.cta` заняты соседними секциями. Скрипт вынесен отдельным блоком — если он упадёт,
шапка, видеофон и курсор продолжат работать.

## Как посмотреть лендинг

Открыть `index.html` в браузере — внешних зависимостей нет.

Локальный сервер, если нужен:

```
python -m http.server 8000
```
